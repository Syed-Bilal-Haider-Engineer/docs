# 🏢 N-Tier Architecture

## Definition

N-Tier architecture divides a system into **multiple layers (tiers)**, each responsible for a specific task.

---

## Common Layers

1. Presentation Layer (UI)
2. Business Layer (Logic)
3. Data Layer (Database)

---

## Flow

UI → Business Logic → Database

---

## Advantages

- Clear separation of concerns
- Easier maintenance than monolith
- Scalable compared to simple architectures

---

## Disadvantages

- Still partially coupled
- Changes affect multiple layers
- Performance overhead due to layering

---

## Use Cases

- Enterprise applications
- Banking systems
- Traditional web systems
