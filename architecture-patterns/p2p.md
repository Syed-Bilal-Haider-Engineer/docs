# 🌐 Peer-to-Peer (P2P) Architecture

## Definition

P2P is a decentralized architecture where **each node acts as both client and server**.

---

## Characteristics

- No central server
- Direct node communication
- Self-organizing network

---

## Advantages

- Highly scalable
- No single point of failure
- Low cost

---

## Disadvantages

- Security risks
- Hard to manage
- Unstable nodes

---

## Examples

- BitTorrent
- Blockchain networks
