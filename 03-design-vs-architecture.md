# 🔹 Design Patterns vs Architecture Patterns

Understanding the difference is very important.

---

## 🧩 Design Patterns

Design patterns solve **small, local problems in code**.

### Characteristics:
- Small scope
- Focus on implementation
- Used inside classes/functions
- Do not define system structure

### Examples:
- Factory Pattern
- Singleton Pattern
- Builder Pattern
- Observer Pattern
- Strategy Pattern

---

## 🏗️ Architecture Patterns

Architecture patterns define the **overall system structure**.

### Characteristics:
- Large scope
- Define system organization
- Control communication between components
- Affect deployment and scalability

### Examples:
- Monolithic Architecture
- Microservices Architecture
- Layered Architecture
- Event-driven Architecture
- Clean Architecture

---

## 🔥 Key Difference

| Feature | Design Pattern | Architecture Pattern |
|--------|--------------|--------------------|
| Scope | Small | Large |
| Focus | Code-level | System-level |
| Purpose | Solve specific problems | Organize entire system |
