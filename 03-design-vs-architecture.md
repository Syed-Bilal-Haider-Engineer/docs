# 🔹 Design Patterns vs Architecture Patterns

## Design Patterns

- Solve small, specific problems
- Used inside classes and functions
- Focus on implementation

### Examples

- Factory
- Singleton
- Builder
- Observer
- Strategy

---

## Architecture Patterns

- Define the structure of the entire system
- Control communication and deployment

### Examples

- Monolith
- Microservices
- Layered Architecture
- Event-driven Architecture

---

## Key Difference

| Aspect | Design Pattern | Architecture Pattern |
|--------|--------------|--------------------|
| Scope | Small | Large |
| Focus | Code | System |
