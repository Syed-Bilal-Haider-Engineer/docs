# 📈 Scalability in System Design

## What is Scalability?

Scalability is the system’s ability to handle **increasing load without performance degradation**.

---

## Types of Scalability

### 1. Vertical Scaling
- Increase server power (CPU, RAM)

### 2. Horizontal Scaling
- Add more servers

---

## Techniques for Scalability

- Load balancing
- Caching
- Database sharding
- Microservices architecture
