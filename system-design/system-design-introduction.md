# 🌐 System Design Overview

## What is System Design?

System design is the process of defining the **architecture, components, interfaces, and data flow** of a large-scale software system.

It focuses on:
- How systems are structured
- How components communicate
- How data flows between services
- How the system scales and performs under load

---

## Goals of System Design

- Scalability
- Reliability
- Performance
- Maintainability
- Fault tolerance

---

## Types of System Design

### 1. High-Level Design (HLD)
- Overall architecture
- Components and interactions
- Technology choices

### 2. Low-Level Design (LLD)
- Internal class design
- Database schema
- API design
