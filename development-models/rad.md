# ⚡ RAD (Rapid Application Development)

## Definition

RAD focuses on **fast development using prototypes and continuous user feedback**.

---

## Characteristics

- Rapid prototyping  
- Continuous user involvement  
- Short development cycles  

---

## Advantages

- Very fast development  
- High user feedback  
- Flexible to changes  

---

## Disadvantages

- Not suitable for large systems  
- Requires skilled developers  
- Hard to scale  

---

## Best Use Cases

- MVP applications  
- UI-heavy systems  
- Internal tools
