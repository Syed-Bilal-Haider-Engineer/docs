# 💧 Waterfall Model

## Definition

The Waterfall Model is a **linear and sequential software development approach** where each phase must be completed before moving to the next.

---

## Phases

1. Requirements Analysis  
2. System Design  
3. Implementation  
4. Testing  
5. Deployment  
6. Maintenance  

---

## Characteristics

- Strict step-by-step process  
- No overlap between phases  
- Heavy documentation  
- No backward movement allowed  

---

## Advantages

- Simple and easy to understand  
- Well-structured and documented  
- Works well when requirements are stable  

---

## Disadvantages

- Very inflexible  
- No user feedback during development  
- Testing happens late  

---

## Best Use Cases

- Government systems  
- Defense applications  
- Projects with fixed requirements
