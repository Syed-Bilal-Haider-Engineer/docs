# 🔺 V-Model (Verification & Validation Model)

## Definition

The V-Model is an extension of the Waterfall model where **each development phase has a corresponding testing phase**.

---

## Structure

### Development vs Testing Mapping

- Requirements ↔ Acceptance Testing  
- System Design ↔ System Testing  
- Architecture Design ↔ Integration Testing  
- Module Design ↔ Unit Testing  
- Implementation ↔ Execution  

---

## Characteristics

- Testing is planned early  
- Strong focus on validation  
- Every phase has a test counterpart  

---

## Advantages

- High quality assurance  
- Early test planning  
- Structured and disciplined approach  

---

## Disadvantages

- Very rigid  
- Not suitable for changing requirements  
- Expensive for large systems  

---

## Best Use Cases

- Medical software  
- Automotive systems  
- Safety-critical applications
