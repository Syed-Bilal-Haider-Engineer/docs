# 🔄 Iterative Model

## Definition

The Iterative Model develops software through **repeated cycles**, improving the system with each iteration.

---

## Cycle

1. Plan  
2. Design  
3. Implement  
4. Test  
5. Evaluate  
6. Improve  

---

## Characteristics

- Continuous improvement  
- Feedback-driven development  
- Early working versions available  

---

## Advantages

- Early detection of issues  
- Flexible to changes  
- Continuous improvement  

---

## Disadvantages

- Requires strong management  
- Can increase cost if uncontrolled  

---

## Best Use Cases

- Large enterprise systems  
- Complex evolving applications
